# Spellings of a ladder rung outside surfaces.css. None stand: a control face
# reads --bgField or --bgControl and a mark on a pane reads --ground. A
# `state:` line is a member's fixed state colour, which outranks the ladder on
# purpose; its reason follows the bar.
# census/rules/surfaces.census.ts holds this list and pins its size; it only
# shrinks.
state: src/design-system/decisioncard.css: .dcard[data-lapsed] { background: var(--bgInset) } | a lapsed proposal drops to --bgInset, a ground no ladder level shares, so it reads as receded at any depth
state: src/design-system/decisioncard.css: .dcard[data-urgency="lapsed"] { background: var(--bgInset) } | a lapsed proposal drops to --bgInset, a ground no ladder level shares, so it reads as receded at any depth
state: src/design-system/sortablelist.css: .sortable-item.is-selected { background: var(--bgInset) } | the row on show takes --bgInset, which no ladder level shares, so it stands out at any depth
state: src/design-system/statstrip.css: .stat-strip > [aria-pressed="true"] > .stat-card { background: var(--bgInset) } | a pressed reading takes --bgInset, which no ladder level shares, so a press reads the same on every level
state: src/design-system/statstrip.css: .stat-strip > button:active:not(:disabled) > .stat-card { background-color: var(--bgInset) } | a reading under the press takes --bgInset, matching the pressed state above

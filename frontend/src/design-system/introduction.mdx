# Margince in Storybook

Every story here renders the component the product ships, with fixture data
and no running stack. Look here for a component before you build one.

## Where things are

- **Get started**: this page.
- **Foundations**: color, type, radius and the brand mark.
- **Components**: the design-system primitives, by what each is for.
- **Patterns**: screen building blocks that are not a page.
- **Shell**: the application frame and the Home page.
- **Records**: the pages a rep works in, and the cards on them.
- **Settings**: every settings card, filed as the settings sidebar files it.
- **Onboarding** and **Signed out**: the first run, and the pages reachable
  without a session.
- **MCP Apps**: the governed tool surfaces and their document forms.
- **Design System**: the kitchen-sink sheets and the agent workbench.

## Checking a story

The **Theme** control in the toolbar switches between light and dark the way
the app does. Check both. The viewport control offers **Phone** at 390px, the
width the phone layout is built for.

## The rules

`frontend/src/design-system/README.md` is the catalog and states the rules.
Read it before you add a component or a story.

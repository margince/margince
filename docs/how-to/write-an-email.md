# Write an email or reply

Open **Write email** from a record to start a new message. Describe what the email should achieve before choosing **Draft with AI**. The draft uses the available contact, lead or account context; choose the recipient and project where those controls are offered.

To reply, choose a conversation and then select the exact message in the left column. The selected row is highlighted. The subject starts with **Re:**, and the line above the recipients names the message and its date. **Reply with…** steers **Draft reply with AI**. Selecting one of your sent emails produces a follow-up to that email.

Hover over **Preview** or press it to read the retained text with paragraphs and the sign-off. **Read full email** opens the full reader, including recipients and attachments. Quoted history can be expanded. These views display the retained normalized text, not the sender's original HTML layout.

**New email** returns to an unanchored message. During an open composer, each selected message keeps its own text, recipients, attachments and project filing. Switching back restores that draft. An AI response arriving after a switch or an edit cannot replace the draft currently being written.

For a reply, the selected message remains the primary evidence. AI also receives bounded recent messages from the same thread that the current reader may access. Review the draft and recipients before sending; generating text does not send email.

# Ratified published-surface changes (check-pkg-freeze.sh). EMPTY by
# design until the first v1+ release tag exists: pre-v1.0.0 the gate is
# ADVISORY (the surface is design-fluid) and consults no allowlist.
#
# From v1.0.0 the gate enforces, and a ratified change is recorded here
# as `<package> <symbol> <reason>`, keyed on its subject like a gatekit
# waiver. The symbol is the name apidiff prints before the first ": "
# of its finding. The reason states the cost in 20+ characters and
# cites the ratifying issue as #<number>. The gate prints the line to
# fill in on failure. Remove an entry once its change has merged: the
# gate warns about entries that match no finding. Package removals are
# never allowlistable (deprecate-then-major cycle, ADR-0120 §3).

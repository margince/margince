# THE DIRECTION-SPELLING DEBT REGISTER — a count, not a permission.
#
# relstrength owns the rule for which side of a relationship wrote a message:
# TheyWroteSQL admits what the contact sent, and WeWroteSQL what we sent. A
# reader that spells `direction = '…'` in its own SQL has answered that question
# for itself, and two answers to one question drift until they disagree where a
# user can see it. One already did: the relationship-change fold counted a
# colleague's reply on the contact's thread as the contact writing.
#
# Every file below spells the column today. The register exists so the census
# can see ALL of them while the debt is paid down, rather than seeing only the
# files that happen to call a renderer.
#
# THE NUMBER IS THE POINT, AND IT OTHERWISE ONLY GOES DOWN. To remove a line:
# move that file onto the rule, or, if it asks about one message rather than a
# relationship, move it to messageStateReaders with a sentence saying so.
#
# There are no per-entry reasons here on purpose. Sixty rationalisations would
# read as sixty permissions, and the gate would retire instead of sharpen.
#
# Sorted, one path per line.
